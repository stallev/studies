# Требования к стилям и UI сайта

Источник: `examples/index.html` (руководство «Google Ads для владельца малого бизнеса в Беларуси»). Там один файл: CSS в `<style>`, контент глав в JSON `PAYLOAD`, рендер и роутер на hash в JS. Для нового сайта берём визуальный язык и набор компонентов. Код разносим по файлам (см. раздел «Архитектура сайта»).

Тексты на сайте подчиняются правилам из `CLAUDE.md` (раздел Writing style rules).

## Принципы

- Стиль в духе Apple HIG: светлая тема, много воздуха, системный шрифт, один акцентный синий.
- Mobile first. Телефон основной, десктоп с боковым оглавлением от 960px. Оглавление скрывается на любом размере экрана.
- Читаемость важнее декора. Тело текста крупное (17px), межстрочный 1.55.
- Доступность обязательна: контраст, фокус, reduced motion, reduced transparency, увеличенный контраст, цели касания от 44px.
- Нулевые внешние зависимости: без CDN, веб-шрифтов и фреймворков. Системные шрифты, CSS и немного JS.

## Типографика

- Корень `font-size: 100%`, тело `1.0625rem/1.55`, `letter-spacing: 0`, `-webkit-font-smoothing: antialiased`.
- H1 страницы: `clamp(2.125rem, 8vw, 3.5rem)`, line-height 1.05, letter-spacing `-.02em`, weight 800.
- H3: `1.4rem`, 1.2, `-.012em`, отступы `2.25rem 0 .75rem`. H4: `1.125rem`, 1.3, отступы `1.5rem 0 .5rem`. Вес заголовков 700.
- `.eyebrow`: `.8125rem`, weight 600, синий, над H1 (название части).
- `.lede`: `1.25rem`, цвет `--text2`, под H1.
- `strong`: weight 650. `code`: `.875em` mono, фон `--code`, радиус 6px, `overflow-wrap: anywhere`.
- Числа в таблицах, KPI, счётчиках: `font-variant-numeric: tabular-nums`.
- Подзаголовки списков (`.partblock h2`): `.8125rem`, капс, `letter-spacing: .06em`, `--text2`. Заголовки колонок таблицы: `.75rem`, капс, `--text2`.
- Подписи: `.cap`, `.8125rem`, `--text2`.

## Раскладка

- Мобильный: верхняя панель (sticky, 52px) и контент. Оглавление выезжает слева поверх контента.
- Контент: `max-width: 46rem`, по центру, боковые поля `1.25rem`. Учитывать `env(safe-area-inset-*)`.
- Десктоп от `960px`: сетка `20rem | 1fr`, залипающий сайдбар с оглавлением на `--bg2`, правая граница `--line`. Поля контента `2.5rem`. Когда сайдбар скрыт, колонка схлопывается до нуля и контент занимает всю ширину.
- Шаг вертикального ритма: `.75rem` между абзацами, `1.5rem` вокруг диаграмм и виджетов, `2.5rem` вокруг `hr`.
- `scroll-padding-top` = высота верхней панели + 12px, чтобы якоря не прятались под ней.
- Ссылка «К содержимому» (`.skip`) в начале body.

## Навигация

- Верхняя панель с материалом (blur 20px, saturate 180%): кнопка показа и скрытия оглавления (на всех размерах, `aria-expanded`), хлебная крошка (часть мелким, название главы жирным, обрезка многоточием), кнопки «назад» и «вперёд», полоса прогресса чтения 2px (`scaleX`).
- Оглавление: поле поиска (мин. 2 символа, debounce 120ms, подсветка `mark`, до 12 результатов), группы по частям, номер главы слева, текущая страница `aria-current="page"` на синем фоне.
- На телефоне оглавление открывается выезжающей панелью (scrim, закрытие по Escape, клику на scrim и выбору главы, фокус возвращается на кнопку). Скрытый сайдбар получает `inert`, чтобы не попадать в порядок табуляции.
- Клавиши: стрелки влево и вправо переключают главы (кроме полей ввода).
- Внизу страницы пейджер: две карточки «Назад» и «Далее» с названиями.
- Чипы разделов страницы под H1 (якоря на H3 внутри главы).
- Главная: hero (eyebrow с датами, H1, lede, статистика, кнопки «Начать» и «Продолжить»), карточки «Маршруты чтения», списки глав по частям с отметкой прочитанного.
- Прогресс чтения и последняя страница хранятся в `localStorage`, с `try/catch` вокруг доступа.

## Компоненты контента

| Компонент | Разметка | Правила |
|---|---|---|
| Таблица | `.tablewrap > table` | Скролл по X, `min-width: 30rem`, шапка sticky на `--bg2`, у `td` есть `data-label` для мобильной карточной раскладки |
| Callout | `.callout` + `.warn` / `.analogy` / `.info` | `warn` оранжевый, `analogy` синий (примеры и аналогии), `info` серый. Без рамки, цветной фон |
| Код | `.codewrap > pre > code.lang-*` + `.copy` | Кнопка «Копировать» в углу, фон `--code`, рамка `--line`, скролл по X |
| Чек-лист | `li.check > .box` | Пустой квадрат 1.15rem с радиусом 5px вместо маркера |
| Кнопка | `.btn`, `.btn.secondary` | Pill, высота от 44px. Основная синяя, вторичная `--blue-soft` |
| Чип | `.chip` | Pill, `--bg2`, высота от 36px, `aria-pressed` для переключаемых |
| Карточка | `.card` | Рамка, тень, заголовок `b`, описание `span` в `--text2` |
| Аккордеон | `details.acc` | Плюс и минус справа, высота summary от 44px |
| Диаграмма / виджет | `.diagram`, `.widget` | Карточка с заголовком H4 и подписью `.cap`. Типы: flow (узлы со стрелками), дерево, горизонтальные бары, стек-бар, Gantt, SVG-линии, слайдеры с KPI и вердиктом |
| KPI | `.kpis > .kpi` | Две колонки, число крупно, подпись мелко, варианты `good` и `bad` |
| Вердикт | `.verdict` + `good` / `warn` / `bad` | Итог калькулятора или диагностики |
| Бейдж | `.badge` | Мелкая оранжевая пилюля рядом с заголовком |

Правила применения:

- Цвет несёт смысл: зелёный хорошо, оранжевый внимание, красный плохо, синий нейтральный акцент. Не использовать цвет без смысла.
- Виджеты интерактивны там, где это помогает считать (калькулятор бюджета, unit-экономика, CPL). Декоративные виджеты не нужны.
- Диаграммы рисуются в SVG и CSS с токенами палитры. Тексты в SVG: `--font`, 11px, `--text2`.
- Таблица подходит для сравнений и справочников. Последовательные шаги пишутся нумерованным списком.

## Состояния и интерактивность

- Фокус: `:focus-visible { outline: 3px solid var(--blue); outline-offset: 2px }`. Убирать outline запрещено.
- Нажатие: `transform: scale(.97)` за 100ms на кнопках, чипах, карточках, табах.
- Hover: фон `--blue-soft`.
- Отключённые элементы: `opacity: .35`, `pointer-events: none`.
- Переход между страницами: сдвиг на 28px с fade, 340ms, `cubic-bezier(.2,.8,.2,1)`. При `prefers-reduced-motion` только fade 150ms.
- `-webkit-tap-highlight-color: transparent`.

## Доступность и адаптивность

- Цели касания не меньше 44x44px (чипы не меньше 36px).
- Семантика: `header`, `main`, `nav`, `aside`, `article`, `section`. У шита `role="dialog"` и `aria-modal`. У иконок-кнопок `aria-label`.
- `prefers-reduced-transparency`: убрать blur, `--material` равен `--bg`.
- `prefers-contrast: more`: границы цветом текста, `--text2` равен `--text`.
- `prefers-reduced-motion`: отключить анимации и `scroll-behavior`.
- Страница не должна иметь горизонтального скролла. Таблицы и код скроллятся внутри своих контейнеров.
- Минимальный viewport 360px. Проверять на 360, 768, 960+.
- Мета: `lang="ru"`, `viewport-fit=cover`, `<title>` вида «Глава · Название руководства».

## Архитектура сайта (решение)

Каталог `website/`, статический сайт без сборки, деплой на Vercel. Данные учебника лежат в JS-объектах, включая данные диаграмм и виджетов, а страницы рендерятся в браузере из этих данных.

- Структура: `index.html`, `assets/` (стили и код рендера), `data/book.js` (метаданные и порядок глав), `data/chapters/chNN.js` (по файлу на главу).
- Данные подключаются обычными скриптами (`window.Book`, `window.BOOK_CHAPTERS`), а не ES-модулями и не `fetch`. Так сайт открывается и с диска, и с Vercel без настроек.
- Глава это объект с массивом блоков `{type: ...}`. Типы блоков: `h3`, `h4`, `p`, `ul`, `ol`, `checklist`, `table`, `callout`, `code`, `diagram`, `widget`, `accordion`, `cards`, `hr`. Схема описана в `website/README.md`.
- Данные диаграмм хранятся в самой главе: `{type: 'diagram', kind: 'flow' | 'bars' | 'stack' | 'tree' | 'gantt' | 'line', data...}`. Код отрисовки общий (`assets/charts.js`). Интерактивные виджеты подключаются по имени (`widget: 'unit-economics'`) с параметрами из данных.
- Текст из данных вставляется через `textContent` и безопасный разбор разметки (`**жирный**`, `` `код` ``, `[ссылка](#/ch3)`). `innerHTML` для контента не используется.
- Маршрутизация на hash (`#/ch3/sec-2`). Реальные URL не нужны, потому что сайт личный и закрыт от индексации (`noindex`).
- Сайдбар с оглавлением можно скрыть кнопкой в верхней панели. На десктопе состояние сохраняется в `localStorage`, на телефоне сайдбар открывается как выезжающая панель со scrim.
- Нижняя таб-панель и bottom sheet из примера не переносятся: их заменяют кнопка оглавления и кнопки «назад» и «вперёд» в верхней панели.
- Строгая политика безопасности (CSP): без inline-скриптов и inline-стилей, стили динамических элементов задаются через CSSOM (`element.style`).
- Целевой вес страницы до 150 КБ без изображений.

## Тексты и учебные материалы

- Структура главы: eyebrow (часть), H1, lede (зачем эта глава), чипы разделов, основной текст по H3, итоговый чек-лист, пейджер.
- Каждая глава отвечает на практическую задачу и опирается на реальные данные проектов (avto-manipulator.by, mogspec.by), а не на абстрактные примеры.
- Термины вводятся таблицей «Термин, расшифровка, простыми словами» и дальше используются без повторных объяснений.
- Аналогии оформляются в `.callout.analogy`, предупреждения о типичных ошибках в `.callout.warn`.
- Команды, запросы (GAQL), скрипты и шаблоны даются в блоках кода с кнопкой копирования.
- Числа приводятся с источником и датой. Цены и интерфейсы платформ меняются, поэтому там, где название кнопки или режима может измениться, ставится пометка «уточнять в интерфейсе».
- Правила текста: см. `CLAUDE.md`. Коротко: без тире как знака препинания, без триплетов для ритма, без «важно отметить», без итоговых пересказов, без эмодзи, кавычки «ёлочки» в тексте.
- Даты в формате `ДД.ММ.ГГГГ`, числа по `ru-RU` (`toLocaleString`), валюты с пробелом перед обозначением.
